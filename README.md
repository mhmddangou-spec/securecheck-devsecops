# SecureCheck

**SecureCheck** est un projet Python pedagogique de verification de criteres de mots de passe.

## Objectifs

- Apprendre les bases de Python
- Comprendre les conditions et les fonctions
- Decouvrir les tests automatiques
- Apprendre Git et GitHub
- Construire progressivement un projet DevSecOps

## Fonctionnalites actuelles

- Verification de la longueur
- Detection des minuscules et majuscules
- Detection des chiffres et symboles
- Evaluation pedagogique de criteres

## Technologies

- Python
- Git
- GitHub

## Execution

Depuis le dossier du projet :

```powershell
python securecheck.py
```

## Avertissement

Ce projet est educatif. Son score ne garantit pas la securite reelle d'un mot de passe.
